# Suporte

## Dúvidas e problemas comuns

Use as [issues](https://github.com/VitorGirardi/neck/issues) para relatar bugs ou sugerir melhorias. Informe:

- versão do Neck;
- versão do Windows;
- o que você esperava;
- o que aconteceu;
- passos mínimos para reproduzir.

O Neck pode criar localmente um relatório sanitizado em **Ferramentas > Suporte**. Revise o arquivo antes de anexá-lo. Ele não é enviado automaticamente.

## Vulnerabilidades e dados sensíveis

Não abra uma issue pública contendo exploração, credenciais, nomes de usuário, caminhos pessoais ou relatórios sensíveis. Use **Report a vulnerability** na aba [Security](https://github.com/VitorGirardi/neck/security) para falar de forma privada com o mantenedor.

## Limites

O projeto é mantido de forma independente e não oferece atendimento emergencial nem prazo garantido. Problemas que envolvam perda de dados, falha física ou instabilidade do Windows também devem ser avaliados por suporte técnico qualificado.
